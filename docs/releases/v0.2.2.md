# v0.2.2 — IBM/Sarama integration v2.10.1 profile

This candidate adds a separate local backport for the official IBM/Sarama
integration v2.10.1. The v2.3.0 profile remains unchanged. This is not an
official DataDog tracer release.

## Exact profile

| Component | Version |
| --- | --- |
| Official Orchestrion | v1.12.1 |
| Official dd-trace-go core | v2.10.1 |
| IBM integration | v2.10.1 + local async producer backport |
| Effective IBM/Sarama | v1.44.0 |

The verifier selects the patch by actual IBM/Sarama package use and the
resolved integration module. It does not silently change the application’s
business dependencies. The v2.3.0 profile continues to allow IBM/Sarama v1.43.2
or v1.44.0.

## Change

The v2.10.1 producer forwarder now holds at most one message pending and selects
between forwarding it to Sarama and draining producer successes/errors. This
preserves the newer integration’s cluster-ID, DSM, service-name-source and
custom producer-tag behavior. It also finishes an unsent pending span on
shutdown.

## Local validation and limits

- Official v2.10.1 source patch applies cleanly and reproduces the checked-in
  `producer.go` exactly.
- IBM integration race tests (`-count=10`) and `go vet` pass for v2.10.1 with
  IBM/Sarama v1.44.0. Existing v2.3.0 matrix profiles still pass.
- Verifier tests and release archive fixture pass. The v2.10.1 fixture resolved
  the intended profile; `--apply` and the non-woven `PATCH_CHECK` passed.
- The complete Orchestrion woven build/test did not complete: its local NATS
  job server timed out during startup. No conclusion about woven runtime
  compatibility is claimed from that attempt.
- Real Kafka A/B testing was not run for this profile: the reproduction Kafka
  port was closed and this environment could not access the Docker daemon. The
  existing v2.3.0 A/B evidence does not substitute for this version’s test.

Thus, this profile is compile/race validated at the integration-module level;
the exact woven application and Kafka fault-recovery path still require a
follow-up run in an environment with Orchestrion’s local job server and the
authorized reproduction broker available.
